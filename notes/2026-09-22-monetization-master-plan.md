## 1. 역할 분리 아키텍처 (확정 방향)

```
로컬 슬롯 1 (무료, 느림)          클라우드 API (유료, 빠름)
 ├─ 대화·검수 대응 (1p 본연)       ├─ 대량 원고 생성 (글 편당 $0.002~0.01)
 ├─ 스케줄링·자가진단 게이트        ├─ 윤문·요약·번역 (배치)
 └─ 최종 수치대조 검증 (지켜야 할 것) └─ 신규 채널 소재 생성 (영상 대본 등)
```

- 원리: **생성은 외주, 검증은 우리**. 외주 산출물은 전부 기존 검수 게이트(수치·URL 100% 대조 + 텔레그램 승인 버튼)를 통과해야 발행. 외주 업체가 승인 버튼을 우회하는 경로 금지.
- 외주 후보(가격은 2026-09 기준 공개가, 가입은 사용자):
  | 프로바이더 | 용도 | 대표가 |
  |---|---|---|
  | DeepSeek API | 대량 생성 1순위 | $0.27~1.10 / 1M tok |
  | OpenRouter | 모델 라우팅·장애 시 폴백 | 마진 소량 |
  | Claude / GPT | 윤문·고품질 편 (주당 소량) | $3~15 / 1M tok |
  | (기존) JeV/OpenRouter 저가 모델 | 주제 선별 — 이미 가동, 일 캡 $0.01 적용 중 | 실측 $0.00008/회 |

## 5. 검수자 규칙 (외주 시대에 더 중요)

1. 외주 산출물 = 초안. **수치·URL 100% 대조 게이트 미통과 시 발행 불가** (원칙 그대로).
2. 원문·API 응답·키 는 절대 외주 프롬프트에 넣지 않는다. 사이트 공개 저장소 PII 게이트(piі_check) 유지.
3. 외주 장애·품질 저하는 JEV 점수 분포로 감시 (주제 통과율 급변 = 모델/업체 교체 신호).
4. 수익 채널 추가 시에도 **사이트 3개 주제 경계는 유지** — 잡지화(저품질) 금지. 신규 주제는 별도 플랫폼·별도 채널에만.
5. 승인형 프로그램 신청은 전부 이 문서의 등록부에 날짜+결과를 남긴다 (거절 기록 = 자산).
